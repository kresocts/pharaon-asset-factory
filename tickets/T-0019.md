# T-0019 - Second controlled GHCR publication

## Goal

Perform exactly one separately approved, controlled, SHA-only production publication of
the canonical `ghcr.io/kresocts/pharaon-asset-factory` container from the exact current
commit on `main`, using the existing secure publishing workflow and the dedicated
self-hosted runner. Keep the ticket in `REVIEW` until the real publication and
independent evidence review succeed.

## Context

The first controlled T-0017 GHCR publication attempt failed before build or push at the
`Refuse existing requested tags` step. T-0018 then normalized handled PowerShell native
exit state so an expected absent registry tag does not leave the process in failure.
T-0019 is a separately approved second controlled publication, not an automatic retry
of T-0017 run 31800647785.

The failed T-0017 attempt did not build or push an image and did not create a SHA,
release, or `latest` tag. The T-0015, T-0016, and T-0018 security contracts are fixed.
The production workflow remains `.github/workflows/publish-container.yml`, and the
canonical image remains `ghcr.io/kresocts/pharaon-asset-factory`.

The owner has configured:

- protected environment `ghcr-publish`
- required environment reviewer
- deployment restricted to `main`
- administrator bypass disabled
- full-length GitHub Action SHA enforcement enabled
- dedicated self-hosted runner `pharaon`
  - labels: `self-hosted`, `Windows`, `X64`, `pharaon-publisher`
  - installed at `D:\actions-runner`
  - manually started with `D:\actions-runner\run.cmd`
  - offline by default
