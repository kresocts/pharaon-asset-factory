# T-0002 — Establish baseline CI

## Goal

Turn the bootstrap metadata check into a documented baseline CI policy suitable for subsequent source code.

## Context

T-0001 includes only the minimal workflow needed to validate repository metadata. The project needs clear triggers, permissions, concurrency behavior, and extension points before implementation expands.

## Dependencies

T-0001 must be `DONE`.

## Allowed scope

GitHub Actions workflow configuration, validation/test entry points, CI documentation, and tests for those entry points.

## Acceptance criteria

- CI runs on pull requests and protected-branch pushes with least-privilege permissions.
- Duplicate superseded bootstrap configuration is removed or consolidated.
- Local and CI commands are documented and produce equivalent results.
- Failures clearly identify the failing validation or test stage.

## Required tests

- Run all repository tests and metadata validation locally.
- Validate workflow syntax and confirm a pull-request CI run passes.

## Out of scope

Worker/reviewer automation, GPU builds, model downloads, cloud provisioning, and deployment.

## Implementation notes

Avoid third-party Actions unless they provide clear value and are pinned according to project policy.
